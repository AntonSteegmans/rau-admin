# Wagenfoto's voor de demo

Zet hier de foto's neer met **exact** deze bestandsnamen (kleine letters, `.jpg`).
De app pikt ze automatisch op — geen code-aanpassing nodig. Ontbreekt een foto, dan
toont de app netjes de "GEEN AFBEELDING"-placeholder (geen crash).

| Bestandsnaam        | Wagen                                      |
|---------------------|--------------------------------------------|
| `v-chiron.jpg`      | Bugatti Chiron Super Sport                 |
| `v-gt3rs.jpg`       | Porsche 992 911 GT3 RS — Manthey Kit       |
| `v-conti.jpg`       | Bentley Continental GT Speed               |
| `v-octa.jpg`        | Land Rover Defender OCTA V8                |
| `v-amggt.jpg`       | Mercedes-AMG GT Roadster                   |
| `v-rr.jpg`          | Range Rover Autobiography LWB              |

**Tips voor de beste look**
- Liggend formaat (landscape), bv. 1600×1000 px of groter.
- De foto wordt bijgesneden om de hero-zone te vullen (`object-fit: cover`).
- `.jpg` aanbevolen; wil je `.png` of `.webp`, laat het weten dan pas ik het pad aan.
